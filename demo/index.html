subrass

ASS/SSA subtitle parser & renderer — pure Rust, compiled to WebAssembly

Basic

The renderer runs on the main thread and draws straight into a canvas overlay. The simplest way to integrate subrass — a few lines of TypeScript.

main-thread

Worker

The renderer lives in a Web Worker. Frames arrive as transferred ArrayBuffers and the UI thread never blocks on WASM work.

web-worker

Both examples auto-load a bundled sample file that exercises most ASS features (karaoke, transforms, rotation, blur, vector drawings). Serve with bun run server.ts after building the WASM package.
